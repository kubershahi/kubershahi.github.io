## Overview

I led the development of aCERT, a web application designed to solve the persistent problem of academic credential verification using blockchain technology. This project explored how Web3 technologies can be applied to create tamper-proof, decentralized systems for educational institutions and employers to verify academic achievements securely.

## Technical Approach

### System Architecture

- **Frontend**: Built a responsive React-based web application for intuitive credential management
- **Backend**: Implemented Express.js server for handling application logic and API endpoints
- **Blockchain**: Deployed smart contracts on Ropsten Testnet using Truffle for credential verification
- **Full Stack**: Created a complete MERN stack solution integrated with Web3 functionality

### What I Worked On

- **Smart Contract Development**: Designed and deployed blockchain contracts for secure credential storage
- **Web3 Integration**: Connected the React frontend with Ethereum blockchain for credential verification
- **User Experience**: Created intuitive interfaces for uploading, storing, and verifying academic documents
- **Security Implementation**: Ensured tamper-proof credential verification through blockchain immutability

## Results

The project successfully delivered:

- A fully functional web application that securely handles academic credential verification
- Smart contracts deployed on Ropsten Testnet demonstrating blockchain integration capabilities
- A seamless user experience that bridges traditional web development with Web3 technologies
- A proof-of-concept showing how blockchain can solve real-world credential verification challenges

## Why This Matters

Academic credential fraud is a significant issue affecting educational institutions and employers worldwide. By leveraging blockchain technology, aCERT demonstrates how decentralized systems can provide transparent, tamper-proof verification while maintaining privacy and security. This project showcases the practical applications of Web3 technologies beyond cryptocurrency.
